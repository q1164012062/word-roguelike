# 🎮 单词肉鸽 (LexiRogue) · 热血拼写

一款将英语单词学习与 Roguelike 机制相结合的轻肉鸽拼写游戏。看中文释义、限时打出英文单词，击败怪物、在真实货架商店买 Buff、结算沉淀学识币、解锁局外永久天赋！

---

## 🚀 快速启动

### 方式一：Python 一键启动（推荐）
在项目目录下运行 `play.py`，将自动启动本地服务并打开浏览器（避免 `file://` 协议对语音朗读和字体的限制）：

```bash
python play.py
```
默认访问：`http://127.0.0.1:8765/`

### 方式二：任意静态服务器
```bash
# Node.js
npx serve .
# Python 自带
python -m http.server 8000
```

## 🌟 核心功能与亮点

### 1. 🏪 真实货架商店体系（金币不再是摆设！）
- **明码标价与分级品质**：
  - **普通品质 (25~40💰)**：急救绷带（立刻回血）、沙漏加持（+1.4s）、跳过权（Tab键跳题）
  - **稀有品质 (45~60💰)**：强效药剂（回2血）、暴击词典（30%暴击）、首字母透视、音节尺、词商之印（收益+50%）、热血连击
  - **史诗品质 (75~95💰)**：错题护盾（免疫伤害）、时间膨胀（流速-20%）、生命灵药（HP上限+1并回满）
- **多买多得**：金币充裕可同时购买多件商品或清空货架。
- **🎲 刷新货架（Reroll）**：花费 15 金币起步刷新商品，随心构建流派。
- **🏦 存钱利息结算**：每保留 50 金币，进店自动结算 10% 存钱利息，玩转“理财流”！

### 2. 🏛️ 局外永久成长 —— 学识祭坛（天赋树）
- 无论通关还是在中途倒下，**单局金币 100% 结算为永久「学识币」**！
- 在标题页点击「🏛️ 学识祭坛」可永久升级：
  - 🎒 **启动资金**：开局自带 +30 / +60 / +100 初始金币
  - 💖 **学者体魄**：开局生命值上限 +1 / +2
  - ⏱️ **思维敏捷**：基础答题时限永久 +0.6s / +1.2s / +1.8s
  - 🔍 **求知若渴**：开局自带“音节尺（显示字母数）”
  - 🏷️ **商贾之友**：局内商店商品享受全场打折（最高 75 折）
  - 📈 **财商精明**：进店利息上限提升至 25 / 40 金币
- 支持 **🔄 100% 无损全额重置天赋**，随心更换加点方案！

### 3. 📚 多重词库与艾宾浩斯 21 天学习法
- 内置切换 CET-4、CET-6 或高中词汇，支持自定义导入 TXT/CSV/JSON。
- 采用 `[0, 0.02, 1, 2, 4, 7, 14, 21]` 天记忆阶梯，生词历经 21 天复习方判定为彻底掌握。

### 4. 🔊 原生 Web Audio API 音效系统
- 购买收银声、掷骰洗牌声、天赋升级充能声、答对音、错误音等全部由代码即时合成。
